## Portfolio projects

### 1. Velora Estates — Luxury Real Estate Website (Concept Project)

**Description:**
A premium real-estate website concept focused on elegant property discovery. Features property listings, location search with price and bedroom filters, favourites, detailed property pages and a viewing request form. Designed separately for desktop browsing and one-handed mobile use, with an editorial visual style and fast, layout-stable image loading.

**Skills:** Next.js · TypeScript · Tailwind CSS · Responsive Web Design · UI/UX Implementation

### 2. Nova Commerce — Premium Ecommerce Website (Concept Project)

**Description:**
A modern ecommerce storefront concept designed around product discovery and a short path to checkout. Includes a product catalogue, collections, instant search and filters, product pages with variant selection, a slide-over cart and mobile-first navigation with a sticky “Add to bag” bar.

**Skills:** Next.js · React · TypeScript · Tailwind CSS · Ecommerce Website Development

### 3. Flowfin — Mobile Finance App (Concept Project)

**Description:**
A personal finance mobile app concept for tracking spending at a glance. Dashboard with balance and budget progress, weekly spending chart, category budgets, searchable transaction history and a dark-first interface. Designed for phones from 360px wide with 44px+ touch targets.

**Skills:** React Native · Expo · TypeScript · Mobile App Development · Mobile UI Design

### 4. Orbit — SaaS Dashboard (Concept Project)

**Description:**
A productivity SaaS dashboard concept demonstrating scalable front-end architecture: collapsible navigation, KPI cards with period comparison, a trend chart, sortable data tables with status badges and removable filter chips. Tables transform into stacked cards on mobile so no data needs horizontal scrolling.

**Skills:** Next.js · React · TypeScript · Dashboard Development · Web Application Development
