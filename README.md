# Lucky Draw 🎟️

تطبيق لوتو للتسلية فقط مبني بـ Flutter — نقاط افتراضية بدون أي قيمة نقدية حقيقية.

## ⚠️ ملاحظة مهمة قبل أي عرض تقديمي
هذا المشروع مبني بالكامل حول **نقاط افتراضية (Virtual Points)**:
- شراء "النقاط" في شاشة `Buy Coins` هو **محاكاة/Demo فقط** — يضيف نقاط افتراضية للرصيد
  مباشرة، وغير متصل بأي بوابة دفع حقيقية (Google Play Billing / Apple StoreKit / بطاقات ائتمان).
- لا توجد أي آلية لتحويل النقاط إلى نقود حقيقية أو سحبها (Cash-out).
- شاشة الإعدادات تعرض دائمًا تنويه: "هذا التطبيق للتسلية فقط، النقاط افتراضية ولا
  تمثل أي قيمة نقدية حقيقية."

تطبيقات اليانصيب/اللوتو بجوائز نقدية حقيقية تخضع لتراخيص قمار/يانصيب صارمة تختلف
حسب كل دولة (وغالبًا محصورة باحتكار حكومي). لو الهدف مستقبلًا ربط جوائز نقدية حقيقية
فهذا يحتاج استشارة قانونية وترخيص قبل أي تطوير إضافي — هذا خارج نطاق هذا الكود.

## المزايا المُنفَّذة
- Splash Screen بانيميشن دخول (scale + fade) ثم انتقال تلقائي للرئيسية.
- شاشة رئيسية: بطاقة رصيد بارزة + زر "العب الآن" + الإحصائيات + السجل + شحن الرصيد.
- شاشة شراء تذكرة: شبكة أرقام 1-49، اختيار حتى 6، Quick Pick عشوائي، تعطيل تلقائي
  للزر لين تكتمل 6 أرقام أو يكفي الرصيد.
- شاشة السحب: كشف الأرقام الفائزة رقمًا رقمًا بانيميشن + haptic feedback، بطاقة نتيجة،
  كونفيتي عند فوز كبير (5 أو 6 تطابقات).
- شاشة السجل: كل التذاكر السابقة مع الفرق بين الربح (أخضر) والخسارة (أحمر).
- شاشة الإحصائيات: عدد مرات اللعب، أعلى جائزة، ورسم بياني (fl_chart) لتطور الرصيد
  آخر 10 محاولات.
- شاشة الإعدادات: Dark/Light Mode، تبديل العربي/الإنجليزي (RTL/LTR تلقائي)،
  إعادة تعيين الرصيد، قسم "About" بالتنويه القانوني.
- Dialog تلقائي لإعادة تعيين الرصيد لو انتهى (أقل من تكلفة تذكرة).
- توليد الأرقام الفائزة عبر `Random.secure()` لعشوائية حقيقية.
- الهوية البصرية: بنفسجي `#6C3CE9` + ذهبي `#FFD700`، خط Cairo (Google Fonts) يدعم
  العربي والإنجليزي.

## هيكلة المشروع
```
lib/
  core/            # ثوابت، ثيم، سلسلة الترجمة الخفيفة (بدون gen-l10n)
  models/          # Ticket
  providers/       # BalanceProvider, SettingsProvider, HistoryProvider (Provider)
  services/        # DrawService (منطق العشوائية وجدول الجوائز)
  screens/         # كل الشاشات السبع المطلوبة
  widgets/         # NumberBall, BalanceCard
  main.dart, app.dart
assets/icon/app_icon.png   # الشعار المرفوع (يُستخدم مع flutter_launcher_icons)
```

## التشغيل (خطوات لازم تسويها بعد استلام المشروع)
هذه البيئة لا تملك Flutter SDK ولا اتصال بـ pub.dev، لذا الكود لم يُبنَ فعليًا هنا
(no `flutter pub get` / `flutter run` تم تنفيذه). اتبع التالي على جهازك:

```bash
cd lucky_draw
flutter create .              # يولّد مجلدات android/ و ios/ الأصلية
flutter pub get
flutter pub run flutter_launcher_icons   # يطبّق أيقونة التطبيق من assets/icon/app_icon.png
flutter run
```

## نقاط قابلة للتوسعة لاحقًا
- الانتقال من SharedPreferences+JSON إلى Hive/SQLite للسجل لو كبر حجم البيانات.
- ربط شاشة "Buy Coins" ببوابة دفع حقيقية (In-App Purchase) عبر حزمة `in_app_purchase`
  الرسمية — يتطلب إعداد المنتجات في Google Play Console / App Store Connect.
- إضافة أصوات فعلية لحظة كشف الأرقام (حاليًا Haptic Feedback فقط كما طُلب كبديل).
